# Knowledge Base

`~/knowledge/` holds reference material for the RX platform and its integrations. Skills hold procedures, and the knowledge base holds facts and known gotchas. Read the relevant part before you write code, write specs, debug, or make an architectural decision.

- `rx/features/`: before you change code for a feature
- `rx/data-models/` and `testing/rspec.md`: before you write specs
- `rx/ui/backoffice-index-patterns.md`: before you build a backoffice page
- `rx/debugging/`: known errors and their fixes
- `rx/urls.md`: URL patterns
- `integrations/netsuite/`: before a NetSuite task
- `workflows/playwright/`: before a Playwright task
